# Play Store listing — Class Routine 2.0

**App name:** Class Routine
**Short description:** 4th Semester Group A and B class routine with offline access.
**Developer name:** Binary Prokashoni

**Full description:**
Class Routine shows the published class schedule for your selected 4th Semester group. See current and upcoming classes, class times, rooms, teachers, and academic announcements.

- Choose 4th Semester Group A or Group B
- Live class status and countdown to the next class
- Published routine updates sync from the online service
- Keeps the last successfully downloaded routine available offline
- Group-specific academic announcements
- Existing profile and personal events support
- No student login or registration

**Category:** Education
**Content rating:** Everyone
**Privacy:** Routine synchronization uses the Class Routine Cloudflare service. See the hosted privacy policy before Play Store submission.
